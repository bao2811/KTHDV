Có 3 lỗi dây chuyền:

Login ECR timeout:
Read timeout on endpoint URL: https://api.ecr.ap-southeast-1.amazonaws.com/
password is empty
Vì login fail nên Docker không có password.

Docker build fail do kéo base image node:20-alpine từ Docker Hub bị lỗi mạng:
Head https://registry-1.docker.io/... EOF
Vì build fail nên không có image local để push:
An image does not exist locally with the tag
Làm lại theo thứ tự này, chạy từng lệnh và chỉ chạy lệnh sau khi lệnh trước thành công.

1. Login ECR lại

aws ecr get-login-password --region ap-southeast-1 --cli-read-timeout 120 --cli-connect-timeout 120 \
  | docker login --username AWS --password-stdin 521590706203.dkr.ecr.ap-southeast-1.amazonaws.com
Kết quả đúng phải có:

Login Succeeded
2. Pull base image trước

docker pull node:20-alpine
Nếu lệnh này vẫn EOF, chờ mạng ổn rồi chạy lại.

3. Build gateway

docker build -f apps/api/gateway/Dockerfile \
  -t 521590706203.dkr.ecr.ap-southeast-1.amazonaws.com/kthdv/gateway:latest .

docker push 521590706203.dkr.ecr.ap-southeast-1.amazonaws.com/kthdv/gateway:latest
5. Redeploy ECS

aws ecs update-service \
  --region ap-southeast-1 \
  --cli-read-timeout 120 \
  --cli-connect-timeout 120 \
  --cluster kthdv-prod-cluster \
  --service gateway \
  --force-new-deployment

  --region ap-southeast-1 \
